# 斗地主规则约定

本文记录规则引擎采用的明确规则版本，避免不同平台规则差异导致实现歧义。

## Task 4 牌型规则

- 顺子至少五张，每个点数一张，点数连续，不允许包含 `2` 或王。
- 连对至少三对，每个点数两张，点数连续，不允许包含 `2` 或王。
- 飞机机身至少包含两个连续三张，机身不允许包含 `2` 或王。
- 飞机带单翼时，每个连续三张对应一张单牌。单翼必须属于不同点数，且不能与机身同点数；不把对子拆成两个单翼。
- 飞机带对翼时，每个连续三张对应一个对子。对子点数必须互不相同，且不能与机身同点数。
- 四带二单采用严格附件版本：四张同点数牌加两张不同点数的单牌，不把一个对子视为两张单牌。
- 四带两对为四张同点数牌加两个不同点数的对子。
- 四带二和飞机带牌都不是炸弹，后续比牌时只能与相同类型、相同长度的牌比较。

## Task 5 比牌规则

- 普通牌型只能与相同牌型、相同总牌数的牌比较，以主体最高点数决定大小。
- 炸弹可以压过任何非炸弹、非王炸牌型；炸弹之间比较四张牌的点数。
- 王炸可以压过任何其他牌型，不存在能够压过王炸的动作。
- 合法动作生成返回具体卡牌 ID 组合。同一点数的不同花色组合会作为不同物理动作保留，方便后续状态机准确移除手牌。

## Task 6 叫分与回合流程

- 叫分按 `user → left → right` 循环，每位玩家每轮一次机会，可选择不叫或叫 `1`、`2`、`3` 分。
- 非零叫分必须高于当前最高分；叫到 `3` 分立即成为地主，否则一轮结束后最高叫分者成为地主。
- 三家都不叫时自动重新洗牌发牌，并轮换下一位玩家首先叫分；随机种子会结合发牌轮次，保证过程可复现。
- 地主获得三张底牌并首先出牌。
- 跟牌必须压过当前牌；首家不能过牌。
- 连续两家过牌后，本轮结束，最后出牌者重新获得自由出牌权。
- 地主先出完牌时地主获胜；任一农民先出完牌时农民团队获胜。
